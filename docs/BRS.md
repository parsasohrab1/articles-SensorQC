# Business Requirements Specification – SensorQC

| ID | Requirement |
|----|-------------|
| BR-1 | Flag suspicious readings in continuous water-quality streams without manual review of every point. |
| BR-2 | Keep the false-alarm rate on reviewed (approved) data known and low. |
| BR-3 | Report which fault types (spike, step, drift, flatline) are detectable at which size, and which are not. |
| BR-4 | State that detection results come from injected faults because real fault labels are not available. |

Out of scope: automatic correction or gap filling, cross-sensor physical models, real fault catalogues.
